# meeting-ops

Covers a meeting end to end: agenda prep, live-note capture, and the follow-up report.

## Commands

| Command | Description |
|---|---|
| `/meeting-prep` | Draft an agenda from the meeting's goal and recent related threads. |
| `/meeting-followup` | Turn a transcript or notes into a summary, action items, and a status update. |

## Bundled skills

- `meeting-summarizer` — condenses a transcript into decisions and action items.
- `weekly-report-writer` — rolls multiple updates (including meeting outcomes) into one report.
