description: Draft the IT/access-request tickets implied by an onboarding checklist
---

Draft the provisioning tickets needed for the new hire described in `$ARGUMENTS`.

1. Read the onboarding checklist for this hire, generating one first if none exists.
2. Map each "access" or "equipment" line item to a specific IT ticket (system, requested role/permission level, due date).
3. Output one ticket draft per system, ready to paste into the ticketing tool.
