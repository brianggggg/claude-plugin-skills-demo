# hr-onboarding

Generates a role-specific onboarding plan and the provisioning requests that go with it.

## Commands

| Command | Description |
|---|---|
| `/onboard-new-hire` | Generate a full onboarding checklist for a new hire's role and team. |
| `/provision-access` | Draft the IT/access-request tickets implied by that checklist. |

## Bundled skills

- `onboarding-checklist` — builds the role-specific checklist itself.
