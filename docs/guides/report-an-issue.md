# Report an Issue

Found a bug, a broken link, or something on the catalog that doesn't look right? Let the team know.

[:octicons-issue-opened-24: Open an Issue](https://github.com/brianggggg/claude-plugin-skills-demo/issues/new){ .md-button .md-button--primary }

## Before you open one

Check the [FAQ](faq.md) first — your question may already be answered there.

## What to include

- What you expected to happen
- What actually happened
- Steps to reproduce, if it's a bug
- A screenshot, if it helps
